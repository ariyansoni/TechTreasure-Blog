
# TechTreasure Blog - Design Guide

## 1. Color Palette

Our website uses a modern dark theme.

- Background Color: Dark Navy (#101020)
- Header Color: Purple Navy (#242450)
- Heading Color: Neon Blue (#00e5ff)
- Text Color: White (#ffffff)

## 2. Typography

- Font Family: Arial
- Main Heading: 32px
- Subheadings: 24px
- Paragraph Text: 18px

We use simple and readable fonts.

## 3. Layout Strategy

- The homepage contains a welcome message.
- The blog page contains different technology articles.
- The header displays the website name.
- Content is arranged in separate sections.
- The design is simple, modern and user-friendly.

## Conclusion

TechTreasure Blog provides a clean and
attractive experience for technology lovers.
